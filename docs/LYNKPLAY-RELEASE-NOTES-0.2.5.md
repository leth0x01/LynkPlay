# LynkPlay 0.2.5

版本代码：56。面向 2023 款领克 06 燃油版、Android 9 车机。

- 同步 DiPlay 0.2.21，保留 LynkPlay 品牌、领克 06 适配、平台签名和系统 UID。上游变更详见 [DiPlay 0.2.21 版本说明](RELEASE-NOTES-0.2.21.md)，其中 BYD 专属功能不代表适用于领克车机。
- 采用上游 USB 重连策略：应用内断开后，等待 10 秒仍未重新枚举时，重新发现同一 USB 节点并复核权限和配置，替换 0.2.4 的超时回退方案。
- 更新领克 06 实车适配文档，区分已采集确认的功能与尚待复验的修复。
- 点击更新安装后，优先通过已授权的本机 ADB 静默安装；失败时回退系统安装器。使用已校验的私有安装包，并防止重复点击。不会在下载完成后自动安装；覆盖安装会中断当前 CarPlay 连接。

可直接覆盖安装旧版 LynkPlay，保留应用设置和配对记录。发布附件包含平台签名 APK 与 SHA-256 校验文件。

本版本未进行新的完整实车验收。USB 软件重连策略和 ADB 静默安装仍需在本车复验；此前实车记录不等同于本版本验证。请在停车状态下测试，详见[车测说明](LYNKPLAY-CAR-TEST.md)与[验证记录](LYNKPLAY-VALIDATION.md)。
