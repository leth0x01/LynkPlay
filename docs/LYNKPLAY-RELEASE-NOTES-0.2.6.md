# LynkPlay 0.2.6

本次更新主要改善应用内升级体验。

- 修复部分车机从应用内安装更新时提示“解析失败”的问题，更新安装不再依赖 ADB。
- 安装前增加确认提示：更新会退出 LynkPlay 并中断 CarPlay，完成后请重新打开应用。
- 安装过程中显示状态，避免重复点击发起多次安装；需要系统确认时，可重新打开确认窗口，也可取消等待确认的安装。
- 保持原有仪表地图支持，沿用相同包名与签名，可覆盖安装并保留设置及配对记录。

## 升级方式

进入 **设置 → 关于 → 检查更新**，下载后按提示安装。

**如果旧版应用内更新仍提示“解析失败”**，请下载 `LynkPlay-0.2.6.apk`，使用车机文件管理器打开并覆盖安装，**无需卸载旧版**。

请在停车状态下更新。安装期间 CarPlay 会断开，完成后重新打开 LynkPlay 即可。

## 验证说明

应用内覆盖升级已在模拟器验证；Android 9 目标车机上的本次安装改进及完整实车体验仍待复验。
