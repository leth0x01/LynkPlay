# 领克 06 高级设置策略

当前状态更新：2026-10-17。策略适用于完整匹配 product/device=`IHU514G`、model=`IHU514G` 或 `BX11`、hardware=`xecarx`、Android API 28 的车机。

规则集中在 `VehicleSettingsPolicy.kt`，设置菜单、搜索和运行时读取使用同一策略。品牌、Android 版本或单个设备字段不能单独触发领克固件规则。

## 固件专属设置

| 设置 | 领克 06 行为 | 依据 |
| --- | --- | --- |
| MTK 解码器低延迟 | 未保存偏好时默认开启；保留用户回退开关；下次连接生效 | 实车使用 `OMX.MTK.VIDEO.DECODER.AVC`，已有成功输出与降级路径 |
| 直接视频输出 | 未保存偏好时默认开启；保留用户回退开关；按现有说明重连 | 实车使用 SurfaceView 直接输出并成功显示 |
| 哈曼车机全屏 | 隐藏且运行时固定关闭 | 本车为亿咖通 MTK 固件，该设置面向哈曼侧栏 |
| 高通低延迟解码 | 隐藏且运行时固定关闭 | 本车为 MTK 解码器，不启用高通专属组合 |

默认值只用于尚未保存该设置的用户。固定关闭项不删除历史偏好，但本车运行时始终返回关闭，避免导入数据或旧版本残留激活隐藏功能。

## 保留设置

以下设置继续使用现有持久化与应用方式：

- HEVC、平滑视频、分辨率和帧率。
- 通话回声消除、语音滤波、音频焦点、缓冲音频和蓝牙音频。
- 分屏、旋转、侧栏和系统栏。
- “仪表盘上的 CarPlay 地图（实验性）”。

仪表地图位于“高级”，修改后按现有重新连接确认流程生效。它只在完整车型组合匹配时使用 `DashboardMapDisplay` 和 AdaptAPI 仪表链路。

## 实车与自动化依据

- 车机报告 `BX11 / IHU514G / xecarx / API 28`。
- 主屏物理尺寸 1920 × 720 / 160 dpi，应用可用区域 1800 × 720。
- 2026-10-16 有线画面与声音正常，物理仪表地图显示成功。
- 现有测试覆盖默认值、用户覆盖、隐藏值运行时屏蔽、部分设备误匹配、菜单与搜索筛选及通用设备不受影响。
- 大字体紧凑、完整和阿拉伯语布局截图已生成并检查。
